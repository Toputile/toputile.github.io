# TopUtile V10 SEO

Cette version conserve la V9 et ajoute :
- 50 pages produit statiques avec URL propre (`/produits/...`)
- 6 comparatifs SEO Auto & Moto
- liens internes entre produits et comparatifs
- balises canonical uniques
- données structurées Product, BreadcrumbList, ItemList et FAQ
- sitemap étendu à toutes les pages importantes
- page Guides recentrée sur Auto & Moto

## Mise en ligne
Téléversez tout le contenu de ce dossier dans le dépôt `toputile.github.io`, puis validez avec Commit changes.

Après déploiement, ne demandez pas l’indexation manuelle des 50 pages : le sitemap les signale à Google. Vous pouvez demander manuellement l’indexation des 3 comparatifs prioritaires : dashcams, boosters, intercoms.
