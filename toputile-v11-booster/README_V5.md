# TopUtile V5 — comparateur avancé

Cette version rapproche surtout **l’architecture et les interactions** de TopUtile d’un vrai comparateur de prix, tout en gardant l’identité propre de TopUtile.

## Ce qui fonctionne maintenant
- Grande recherche avec suggestions.
- Navigation par catégories.
- Catalogue avec filtres et tri.
- Fiches produits détaillées.
- Favoris / Ma sélection.
- Comparaison de 2 à 3 produits côte à côte.
- Prix cible enregistré localement.
- Tableau d’offres avec Amazon comme premier marchand.
- Zone d’historique de prix prête à recevoir de vraies données.
- Produits similaires.
- Espace personnel local.
- Liens Amazon Partenaires conservés.

## Ce qui n’est volontairement pas simulé
TopUtile n’invente aucun prix, aucune courbe de prix, aucun avis client, aucune note marchand et aucune disponibilité. Pour rendre ces fonctions réellement comparables à celles d’un grand comparateur, il faudra connecter des flux/API marchands et ajouter un petit backend.

## Mise en ligne
Dans le dépôt `toputile.github.io` :
1. Ajouter un fichier → Téléverser des fichiers.
2. Envoyer tout le contenu de ce dossier V5.
3. Valider avec Commit changes.
4. Attendre le déploiement GitHub Pages.
5. Ouvrir `https://toputile.github.io/?v=5` ou faire Ctrl+F5.
