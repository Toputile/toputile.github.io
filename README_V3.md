# TopUtile V3 — installation simple

Cette V3 est volontairement plus minimaliste : moins de blocs, moins de texte à l’écran, plus d’espace et seulement trois produits principaux sur la page d’accueil.

## Mise à jour sur GitHub
1. Ouvre ton dépôt `toputile.github.io`.
2. Choisis **Ajouter un fichier → Téléverser des fichiers**.
3. Sélectionne tout le contenu de ce dossier V3.
4. Envoie les fichiers en conservant la même arborescence (`assets`, `guides`, etc.).
5. Valide avec **Commit changes** sur la branche principale.
6. Attends 1 à 3 minutes puis recharge `https://toputile.fr/` avec Ctrl+F5 si nécessaire.
