# TopUtile V12 — Multi-marchands ready

Cette version conserve le design et le contenu de la V10/V11, mais remplace l'architecture « Amazon uniquement » par un moteur multi-marchands.

## Actif aujourd'hui
- Amazon.fr

## Préparé mais invisible tant que non activé
- Rakuten
- Cdiscount
- Fnac
- Darty

## Fonctionnalités
- tableau d'offres commun à toutes les pages ;
- 50 fiches SEO équipées du moteur multi-marchands ;
- catalogue qui compte les offres disponibles ;
- filtre par marchand actif ;
- classement par prix total uniquement si des données de prix fiables existent ;
- aucun faux prix et aucun marchand « en attente » affiché au public ;
- activation future depuis un seul fichier : `assets/js/merchant-data.js`.

Voir `ADMIN_MARCHANDS.md` pour les étapes d'activation après acceptation Awin.
