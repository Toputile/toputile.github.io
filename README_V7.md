# TopUtile V7

Version plus professionnelle de TopUtile, avec finition visuelle améliorée et correction des visuels manquants.

## Ce qui change dans la V7
- style plus premium et plus propre
- hiérarchie visuelle renforcée
- meilleure typographie
- cartes produits plus homogènes
- catalogue plus crédible
- visuels intégrés pour éviter les images cassées
- fallback local si une image distante ne charge pas
- liens Amazon conservés

## Mise en ligne
1. Ouvrir le dépôt GitHub `toputile.github.io`
2. Ajouter un fichier → Téléverser des fichiers
3. Envoyer tout le contenu du dossier `toputile-v7`
4. Commit changes
5. Ouvrir `https://toputile.fr/` et faire Ctrl + F5
