# TopUtile V8 — catalogue Auto & Moto

Cette version remplit TopUtile avec **20 références Auto & Moto réelles**.

## Familles intégrées
- Supports téléphone & connectivité
- Gonflage & pression
- Batterie & démarrage
- Dashcams
- Entretien & nettoyage
- Équipement moto
- Intercoms moto

## Images
Les fiches utilisent des photos du produit / modèle exact lorsque la source est disponible. La majorité provient des fabricants. Certaines références utilisent une image exacte de revendeur lorsqu’un visuel fabricant directement exploitable n’était pas disponible.

## Amazon Partenaires
Tous les boutons Amazon utilisent le tag `toputile01-21`. Trois références disposent déjà d’un lien produit direct connu ; les autres utilisent une recherche Amazon affiliée ciblée. Tu pourras remplacer progressivement ces recherches par des liens Mobile GetLink directs sans toucher au reste du site.

## Prix
Aucun prix Amazon fixe n’est affiché : l’utilisateur consulte le prix actuel chez Amazon.

## Important pour les images Amazon
Pour intégrer à grande échelle les images et métadonnées Amazon de façon durable, la bonne évolution est l’utilisation des outils officiels Amazon Partenaires / Product Advertising API, plutôt que de copier manuellement des images Amazon.

## Mise en ligne
1. Décompresser `toputile-v8.zip`.
2. GitHub → dépôt `toputile.github.io`.
3. Ajouter un fichier → Téléverser des fichiers.
4. Envoyer tout le contenu du dossier V8.
5. Commit changes.
6. Ouvrir `https://toputile.fr/` puis faire Ctrl + F5.
