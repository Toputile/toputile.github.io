# TopUtile V15 — Identité Google

Cette version conserve intégralement la V14 et ajoute seulement les signaux d’identité du site.

## Ajouts
- favicon TopUtile en ICO, PNG et SVG ;
- icône 48x48 compatible avec les recommandations favicon de Google ;
- apple-touch-icon et manifest ;
- `og:site_name = TopUtile` ;
- `application-name = TopUtile` ;
- données structurées `WebSite` sur la page d’accueil avec `name = TopUtile` ;
- données structurées `Organization` avec logo TopUtile.

## Après mise en ligne
1. Vérifier `https://toputile.fr/favicon.ico`.
2. Dans Search Console, inspecter uniquement la page d’accueil.
3. Cliquer sur « Demander une indexation » une fois pour la page d’accueil.
4. Patienter : Google choisit lui-même quand il remplace « GitHub » et l’icône générique dans les résultats.
