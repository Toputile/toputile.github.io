# V18 Cosy & colorée

Cette variante reprend la V18 structure claire mais avec :
- un design plus chaleureux et coloré ;
- moins d'effet « hôpital / document Word » ;
- un menu plus simple ;
- plus de photos produit sur l'accueil et sur la page Univers/Catégories ;
- des intitulés plus doux : `Univers`, `Conseils`, `Produits`.

À mettre en ligne en remplaçant les fichiers actuels du dépôt GitHub.
