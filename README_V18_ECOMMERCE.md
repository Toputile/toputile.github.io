# TopUtile V18 — E-commerce moderne

Cette version garde la base SEO et multi-marchands de la V18 mais adopte une présentation plus proche d'un grand site e-commerce moderne :
- gros moteur de recherche ;
- en-tête sombre et navigation simple ;
- accent orange chaud ;
- catégories visuelles avec photos produit ;
- davantage de produits visibles dès la page d'accueil ;
- cartes orientées « voir les offres » plutôt que répétition du mot « comparer » ;
- guides relégués après les produits ;
- rendu mobile horizontal pour les produits et conseils.

Le site ne copie pas l'identité visuelle d'Amazon et conserve l'identité TopUtile.
